## 原始指令

> 客户端目标，即能作为单独的agent工具，同时可可作为员工的聊天工具。即一台电脑既可以让员工正常使用，同时也可以让员工使用的同时，agent（即hermes）在后台执行任务。也可以在无员工使用时，agent（hermes）自主运行。

## 需求归纳

- 一个客户端同时支持原生员工聊天与独立 Agent 工作入口；两者不是互斥模式。
- Hermes 在员工使用电脑时并行后台执行，无人操作时可按既有授权继续，不限于空闲时启动。
- 本地独立使用不应要求连接组织聊天服务器；模型连通性与是否完全离线另行配置。
- Agent 生命周期和 UI 生命周期分离；任务权限不来自“员工当前在线”。
- 无人操作、锁屏、关闭 UI、OS 注销、睡眠、关机是不同条件，不能统称“无人值守全部支持”。
- 本次明确 Hermes 后台运行目标，应实际核实上游集成，不以历史“框架思路”澄清代替本次要求。
