# 验收矩阵

| 流程 | 必测结果 | 不能替代的证据 |
| --- | --- | --- |
| 合法成员发任务 | 正确会话、任务、事件、结果 | 不能只测 Mock 文本 |
| 越权读/写/发 | 403/拒绝且零副作用 | 不能只隐藏按钮 |
| 重放 webhook | 不新增消息/任务 | 不能只依赖随机 UUID |
| 工具参数错误 | 结构化错误且不执行 | 不能由模型自称修正 |
| 生成文档 | 产物绑定 task/run/owner，round-trip 正确 | 不能只看文件存在 |
| 审批后外发 | 载荷 hash、目标、版本一致且有回执 | 模拟 gateway 只能标 simulated |
| 外发超时 | unknown/对账，不盲重发 | 不能默认失败后重试 |
| 取消竞态 | 合法终态唯一，后续步骤停止 | 不能只测按钮返回 |
| 服务重启 | 待办/审批/事件可恢复 | 内存队列测试不够 |
| 真实模型 | provider 协议、tool call、超时可解释 | Mock 不算真实模型 |
| 真实 Hermes | 固定版本、隔离、工具/会话/取消契约通过 | 同名 TS 循环不算 |
| UI/Electron | 登录、状态、响应式、键盘、控制台无错误 | 截图不算流程验收 |
