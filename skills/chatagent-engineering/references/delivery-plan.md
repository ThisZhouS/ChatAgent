# 开发阶段

## Gate 0：方向与环境

确认主产品是内网原生聊天还是第三方适配；测量 Node/pnpm、模型网关、数据库、Hermes 入口、网络与凭据状态。记录 ADR，不编造 DeepSeek Harness 命令或 Hermes 集成结果。

## Gate 1：可信消息

先做认证、组织/成员、对象授权、会话成员、入站签名/去重和自回复抑制。验收：双用户跨资源拒绝，伪造 sender/重放 webhook 不创建任务。

## Gate 2：可信任务

结构化 outcome、状态机/CAS、取消竞态、恢复/租约、事件游标、失败通知。验收：provider 错误为 failed；取消不被完成覆盖；重启不丢待办。

## Gate 3：受控办公

文件归属、Word/Excel round-trip、大小和解析预算、artifact ACL。验收：并发产物不串任务，下载/转发再次授权。

## Gate 4：副作用交付

审批、action digest、outbox、幂等、回执和 unknown 对账；先接一个真实或批准的内网网关。验收：未审批零发送；重复 webhook/重试不重复外发。

## Gate 5：模型与 Harness

用能力探针验证真实模型的工具调用、thinking/推理字段、截断、超时和取消；用固定上游版本验证 Hermes 的启动、工具注册、会话隔离和崩溃回传。Mock 只能作离线门。

## Gate 6：体验与发布

工作台展示身份、任务、审批、产物、交付状态和错误恢复；浏览器、Electron、部署、备份恢复和安全回归通过后才发布。每阶段保留命令、日期、环境、产物、失败和剩余风险。
