# 交互设计

主流程围绕“我委托了什么、AI 正在做什么、需要我批准什么、产出了什么、是否已交付”组织，而不是围绕模型推理文本。任务卡显示请求者、AI 账号、会话、状态、当前步骤、产物、审批、交付回执、错误和恢复入口。

必须有：AI 明确徽标与负责人；新建任务的范围/附件/收件人确认；运行中取消；等待输入/审批；成功、失败、unknown、重试和恢复；文件版本与预览；权限拒绝的原因但不泄露内部策略。

不要在 UI 展示完整 reasoning_content；显示可审计的操作摘要和工具状态。禁用发送按钮不是授权控制。所有下载、审批和取消请求由服务端再次校验。

桌面端优先稳定双栏：会话/任务列表 + 当前详情；窄屏折叠详情。长文本、中文文件名、表格溢出、键盘焦点、加载/空/错误/断线状态均要验证。SSE 断线时显示重连和历史补发，而不是清空状态。
