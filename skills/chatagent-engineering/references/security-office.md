# 办公数据最小规则

文件和消息按不受信任输入处理。限制大小、解析时间和输出预算；禁止宏、外链和任意本地路径。生成文件后重新解析验证类型与来源，产物绑定 task/run/owner/organization 和 hash，所有下载、预览、转发再次授权。

外发、群发、覆盖/删除是副作用：审批绑定不可变内容、接收者和附件版本，写 outbox/audit，使用业务幂等键与回执。超时且无法查证时标记 unknown，不能盲目重发。模拟 gateway 的 ok 只能标记 simulated。

Webhook 必须先验证签名、时间窗和去重；不伪装真人、不绕过平台风控、不把内网可达当安全、不把前端按钮或难猜 URL 当权限控制。
